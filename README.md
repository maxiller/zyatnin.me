# zyatnin.me

Персональное портфолио и технический блог Макса Зятнина. Статический сайт на Eleventy с поддержкой русского, английского и иврита, светлой и тёмной тем, публикуется на GitHub Pages.

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:5000`.

| Команда | Назначение |
| --- | --- |
| `npm run build` | Сборка в каталог `_site` |
| `npm run dev` | Локальный сервер с горячей перезагрузкой |
| `npm run start` | То же, что `npm run dev` |
