# zyatnin.me

Персональное портфолио и технический блог Макса Зятнина. Статический сайт на Eleventy с поддержкой русского, английского и иврита и двумя видами сайта — «Лидер поддержки» (светлая офисная тема) и «Разработчик» (тёмная тема в стиле IDE); публикуется на GitHub Pages.

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт будет доступен по адресу `http://localhost:5000`.

| Команда | Назначение |
| --- | --- |
| `npm run build` | Сборка в каталог `_site` |
| `npm run dev` | Локальный сервер с горячей перезагрузкой |
| `npm run start` | То же, что `npm run dev` |

## Отложенные статьи

Публикация включается датой: статья с `date` в будущем не попадает в сборку и появляется в индексах, лентах и sitemap после 00:00 UTC этого дня, в ближайшей пересборке (GitHub Pages пересобирается по push и ежедневно по расписанию). `draft: true` в front matter скрывает статью насовсем — до снятия флага. Правило одно и живёт в `lib/published.js`; шаблоны и коллекции о нём не знают.

Локальный предпросмотр: `npm run dev` показывает и отложенные статьи, и черновики. Для обычной сборки с ними: `INCLUDE_FUTURE=1 npm run build`. После такой сборки удалите `_site` — Eleventy не стирает файлы, которых больше нет в сборке, и `scripts/check-seo.js` сравнит новую сборку со старыми страницами.
