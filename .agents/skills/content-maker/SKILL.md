# Контент-мейкер

Весь контент всегда пишется на всех языках, используемых в проекте: русском, английском и иврите.

## Правило

При создании или изменении любого пользовательского контента выполняйте его перевод на все три языка в рамках одного изменения:

- Языковые версии сайта находятся в `src/ru/`, `src/en/`, `src/he/`. У каждой версии одинаковая структура подразделов (`blog/`, `dev/`, `posts/`, `projects/`).
- Страница, пост, проект или статья добавляются одновременно во все три языковых каталога. Не оставляйте контент только на одном языке.
- При правке существующего контента вносите эквивалентные изменения во все языковые версии.
- Тексты интерфейса (i18n-ключи) находятся в `src/_data/i18n/`; новые ключи добавляются и обновляются во всех языковых файлах синхронно — см. [ключи i18n](../../../docs/SRS.md#72-ключи-i18n).

## Профиль поста

Профиль задаётся полем `view` front matter: `leader` («Лидер поддержки») или `dev` («Разработчик»). Пост существует только в одном профиле:

- Перед созданием поста определите по тематике, какому профилю он подходит: управленческое и коммуникационное содержание (процессы, найм, KPI, границы ролей, клиентский успех) — `leader`; техническое (контейнеры, Linux, автоматизация, инструменты, разработка) — `dev`.
- Пост не дублируется в другой профиль: для него создаётся файл только с одним значением `view` (требование FR-111).
- Если задача предусматривает написание нескольких постов сразу, все они размещаются в одном профиле — не разделяйте пакет постов по двум видам.

## Метки поста

Поле `tags` front matter задаёт до трёх меток, по которым читатель переходит между статьями (требования FR-118–FR-121):

- Метка — ключ из словаря `tags.names` в `src/_data/i18n/*.json`, вид `[a-z0-9-]+`; подпись существует только в i18n, в front matter её не дублируйте.
- Определите тематику поста и поставьте от одной до трёх меток: самую точную — первой. Если подходящей метки нет, добавьте новый ключ сразу во все три языковых файла.
- Набор меток одинаков во всех языках одной статьи: правьте `tags` во всех трёх файлах одновременно.
- Сборка падает, если число меток выходит за пределы 1–3 или ключа нет в `tags.names`.

## Проверка

- SEO-артефакты (`sitemap.xml`, Atom-ленты, JSON-LD) генерируются из тех же коллекций при сборке: если страница есть не во всех языках, проверка `npm run build` завершится ошибкой (`scripts/check-seo.js`).
- Перед завершением убедитесь, что для каждого нового или изменённого файла контента существуют параллельные файлы в двух других языковых каталогах.
